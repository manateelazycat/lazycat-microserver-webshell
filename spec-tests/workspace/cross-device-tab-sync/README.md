# 两个窗口的新标签数量同步

规格：[REQ](../../../spec/workspace/cross-device-tab-sync/REQ.md) · [AC](../../../spec/workspace/cross-device-tab-sync/AC.md)。环境与目标：[ENVIRONMENT](../../ENVIRONMENT.md)。

## 操作流程

1. 同时打开桌面和移动布局两个浏览器窗口，登录同一账号、打开同一工作区。
2. 确认两个窗口的标签数量一致，记录初始数量 N。
3. 在移动窗口点击新建标签。
4. 等待桌面窗口自动同步，检查两端标签数量均为 N+1。

观察窗口不手动刷新、不重新打开页面。同步等待上限为 12 秒；超时时输出窗口名称、预期数量和实际数量。

## 场景边界

本项只检查新建标签后的数量同步。原有关闭标签同步、焦点、DOM/Canvas 身份、画布可见性、连接数和持续输出检查已按用户确认的范围移除。结束时删除本项创建的标签仅用于资源清理，不属于关闭同步验收。

检查 N+1 是为了避免两端都没有变化却因数量相等而误报通过。测试不删除账号原有标签。

## 执行

在产品根目录运行：

```sh
./run-ac.sh --selector workspace/cross-device-tab-sync
```

入口自动构建并使用最新本地前端，真实后端和认证配置来自 `.env`。本项使用两个真实 Chrome 窗口；移动窗口是浏览器移动布局，不代表 Android 原生设备覆盖。

## 证据

`tab-counts.json` 记录操作前后数量、预期数量、新建标签 ID 和同步耗时；`desktop-tabs.png` 与 `mobile-tabs.png` 保存两个窗口的画面。详细事件与 trace 由共享运行器保存。

最新真实验证：两个窗口均从 4 个标签增加到 5 个，同步耗时 1.117 秒；场景耗时 21.366 秒、入口总用时 23.256 秒，通过。见 [完整报告](../../../reports/simple-tab-count-20260907T162721.json)。
