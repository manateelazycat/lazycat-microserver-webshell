# 终端重任务调度

`createTerminalWorkScheduler()` 由 `global-runtime.js` 创建一个页面级实例，供输出、绘制和几何 owner 注入使用。调度器只持有任务与时间预算，不持有终端协议或工作区状态。

任务按 owner/key 合并，每轮共用 8ms 预算，每个任务至多执行一次；可见任务优先，等待时间提升后台任务优先级。一个 RAF 与 fallback timer 互相取消，后台页面仍可推进。同步 fence 只能消费剩余预算。预算在同步调用之间检查，无法抢占已进入的 WASM 调用。

各 owner 必须在连接切换、会话销毁时取消过时任务，并在执行时复核状态。页面销毁释放整个调度器；失败交回会话恢复 owner。
