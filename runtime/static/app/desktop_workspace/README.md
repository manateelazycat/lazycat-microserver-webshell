# PC 工作区

本模块独立拥有新版 PC 侧栏、实例分组收放和按实例分组的总览 DOM。唯一入口是 `createDesktopWorkspaceController()`；全局运行时只注入实例快照、工作区命令、预览和布局回调，并编排 start/dispose。

`directory_controller.js` 通过已鉴权的 `api/workspace?inspect=1` 查询后台实例的元数据，不建立终端 WebSocket、不做历史回放，也不把后台快照应用到当前工作区。Provider 优先使用专用只读检查；物理机未提供该可选路由时，兼容既有工作区读取接口，保持已打开会话，不因路由缺失提示更新 PC 客户端。旧核心保留其首次读取时的默认工作区初始化语义，兼容路径不触发重启恢复、会话重建或尺寸更新。并发最多三个，新版模式中每 15 秒更新，收起侧栏仍追踪后台未读；页面隐藏时不请求，切出新版模式后取消请求。selector、工作区 generation 和请求版本共同隔离快照。预览复用 overview 的独立图片存储，缺少画面时显示无预览。

首次连接遇到网络失败、超时、408/425/429 或 5xx 时，以 250/750/1500/3000ms 间隔自动重试，随后由正常刷新继续恢复。请求按 selector 单飞，每个实例独立恢复，不以一个慢实例阻塞整轮刷新；退避期间释放请求槽位。物理机查询包含票据与设备网关连接，单次允许 45 秒；容器查询仍为 12 秒。认证、协议更新或无效会话身份不做快速重复请求，保留明确提示，后续刷新仍重新检查，环境恢复后无需点击实例。页面隐藏、切出新版模式或 dispose 同时取消请求和退避计时；恢复可见或网络上线后自动重新加载，迟到结果不能覆盖当前状态。

前端只有在容器响应显式声明 `agent_protocol_update_required` 时才显示协议更新提示，不通过通用 409 状态码推断 PC 客户端版本。

目录分别维护已确认元数据和已应用的活动 selector/generation；工作区切换期间保留缓存，只有当前代次完成权威 state apply 后才读取 live tab registry。`pending`、连接重试和确认空列表有不同语义；侧栏和预览共享目录计算的提示，临时清空 registry 不产生空列表提示闪烁；确认无会话后，侧栏和分组预览隐藏提示节点，列表区域留空，保留加载、连接及错误反馈。等待新工作区期间点击会话通过现有 refresh owner 完成读取，不把暂未应用的会话误报为已关闭。

侧栏中的会话对应现有 tab，原分屏完整保留。实例标题行的名称靠左，右侧依次放置新建会话和展开收起图标。工具栏左侧为向左箭头的收起按钮，右侧依次复用文件上传和菜单入口；终端预览按钮留在原顶部栏，不移入新版侧栏。切回传统 PC 或移动布局时恢复原 DOM 位置。菜单由 instances view 在打开时挂到 body 浮层，锚定按钮下方，按可见窗口边界平移并限制高度，允许跨出侧栏范围。终端本体不属于本模块。

工具栏右侧图标统一为 16px、1.5px 线条和侧栏弱化文字色；文件上传在新版布局中使用线条纸飞机图形，切回传统或移动布局时还原原图标。按钮保留原点击区域及居中对齐，图标视觉大小与侧栏其他操作一致。

会话快捷键继续由 `app/shortcuts/` 分派，双击、F2 和改名快捷键复用 `workspace/tab_label_controller` 的原位编辑器，通过只读锚点定位到侧栏；Enter/失焦保存、Escape 取消及输入法保护沿用原实现。右键、Shift+F10/ContextMenu 键调用 `terminal/interaction.openTabMenu()`，菜单操作及当前自定义快捷键保持一致。中键关闭也走已有的会话关闭确认。

`reorder_controller.js` 只拥有鼠标和触摸长按的纵向拖拽、占位、自动滚动、取消和动画资源；不拥有工作区数据。会话排序使用已声明的 `tab_reorder_anchor` 能力，单次提交原子 `reorder_tab`，保留焦点和分屏，失败恢复顺序并通过现有 owner 刷新。实例顺序保存在 `${storagePrefix}.desktopInstanceOrder`，仅调整此浏览器的展示，新增实例追加，跨标签页通过 storage 事件同步。拖拽期间目录更新留在数据层，结束后统一呈现；不跨实例移动会话。低动态效果偏好关闭位置补间。

`session_presentation.js` 跟踪所有真实前台进程，不以 Agent 名称白名单决定是否展示。Codex 复用已有精确识别，其他入口按可执行文件、解释器脚本或模块名展示；不解析 OSC 标题，不把命令参数、令牌或内联代码输出到 DOM。后台元数据由服务端只读检查更新，不新增终端连接或活动轮询；该状态表达进程活动，不猜测 Agent 内部的思考/等待阶段。

`session_notifications.js` 区分前台进程活动和应用工作状态；未读由应用完成次数推进，不能把持续输出或进程仍驻留当作完成。当前实例复用原有 4 秒 activity，后台实例复用目录查询；初次读取只建立基线。状态和完成次数按 selector、工作区及历史代次保留，短任务即使在两次查询间完成也能提示未读。返回实际查看的会话时只清除其未读，记录已查看输出位置以排除晚到的完成元数据；跨实例切换的中间默认会话不会被提前确认。浏览器标题汇总全部实例，收起侧栏仍更新。

侧栏在会话名称左侧预留固定状态位置，不再显示额外的终端图标：工作中显示 8 像素环逐帧亮起，完成且未读显示绿色对钩，出错显示红点。错误优先于工作，工作优先于未读；等待输入/授权保持静态，不显示成功或错误。状态变化不移动标签；只在状态变化时替换图标，减少动态效果时使用静态工作图标。文字提示与辅助名称表达相同状态。

`program_status.js` 是已连接旧核心的实时兼容观察器，只消费成功的 live 写入，不解析历史回放；支持 OSC 7501、21337、9;4、133 和明确的标题状态/进度字符，不用工具名称白名单或输出静默超时猜测工作结束。新版核心的状态为权威来源，保留旧字段缺失才能启用此兼容。未知信号只沿用前台进程活动，普通通知、等待授权和失败不会变为成功完成。旧核心的后台实例不能提供完整应用状态，不为此额外连接或强制重建会话。

Codex 状态协议来源：[v0.163.0 的 terminal_program_status.rs](https://github.com/openai/codex/blob/rust-v0.163.0/codex-rs/tui/src/terminal_program_status.rs)；较早版本兼容其标题进度，不读取工具的会话文件或用户配置。

新版工作区外框统一预留 `--lzc-safe-area-inset-top`，绝对定位的侧栏也从同一安全区下沿开始，不再单独叠加顶部 padding。终端和侧栏随安全区及窗口变化一起适配；选项菜单的操作区在新版中不保留原实例列表的分隔线和底部间距。

侧栏收起后取消终端左侧 margin，终端使用完整横向空间；向右箭头的展开按钮浮在左上角，不再为按钮单独预留空白。恢复侧栏时复用现有几何与过渡流程。

会话行背景两侧沿用列表相同的 8px 留白，悬停与选中背景保持左右对称；内容通过 20px 左内边距保留 12px 层级缩进，以区分实例标题与子会话；任务状态槽和动画采用与 12px 标题字号一致的 1em 尺寸，空闲时也保留同宽位置，名称区域延伸到实例箭头右沿。Codex 等工具入口标记放在名称右侧，左侧始终只保留固定宽度的任务状态位置，标记出现或消失不改变名称左侧起点；关闭按钮仅在交互时出现，平时不保留空白。`session_label.js` 通过实际字体度量和 ResizeObserver 将名称显示为最多两行，足够容纳时显示完整名称，超过两行时在中间省略并保留开头与末尾；显式分行按 Unicode 字素边界切分，不拆开 emoji 或组合字符。字体加载和标签宽度变化后重新计算，悬停、辅助名称及原位改名保留完整名称，删除会话和销毁时释放观察。

`sidebar_resize_controller.js` 独立拥有右侧分隔线的 pointer capture、键盘操作和 RAF 合并，最大宽度为窗口的三分之一，最小宽度为 160px（受最大值约束）。宽度保存在 `${storagePrefix}.desktopSidebarWidth`，窗口变窄时仅约束显示宽度。拖动经注入的 begin/update/end 命令复用终端交互式 resize，不新建会话或改变分屏。取消、切换实例、切换布局、收起及 dispose 统一结束交互；Escape 取消当前拖动，方向键、Home/End 可调整宽度。

手工验证：容器/物理机/停止实例、跨实例同名会话、包含分屏的会话、创建/关闭/双击改名、预览选择、侧栏及实例连续收放、减少动态效果、传统布局开关、移动布局和窗口尺寸变化；冷启动或短暂断网后自动恢复、后台失败保留已有会话、取消与恢复加载、平板/折叠屏顶部安全区及菜单分隔线。产品合同见 `spec/workspace/desktop-navigation/`。
