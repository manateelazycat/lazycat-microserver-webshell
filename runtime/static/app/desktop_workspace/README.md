# PC 工作区

本模块独立拥有新版 PC 侧栏、实例分组收放，以及所有非嵌入布局共用的按实例分组总览 DOM。唯一入口是 `createDesktopWorkspaceController()`；全局运行时只注入实例快照、工作区命令、预览和布局回调，并编排 start/dispose。

大屏折叠设备的内外屏由 `app/layout/` 统一判定：外屏恢复手机导航，展开内屏启用新版 PC 侧栏；这里只切换界面模式，不重置实例或会话。PC 导航布局与触摸输入能力独立，软键盘开合不改变内屏导航模式。

`directory_controller.js` 通过已鉴权的 `api/workspace?inspect=1` 查询后台实例的元数据，不建立终端 WebSocket、不做历史回放，也不把后台快照应用到当前工作区。Provider 优先使用专用只读检查；物理机未提供该可选路由时，兼容既有工作区读取接口，保持已打开会话，不因路由缺失提示更新 PC 客户端。旧核心保留其首次读取时的默认工作区初始化语义，兼容路径不触发重启恢复、会话重建或尺寸更新。并发最多三个，新版模式或任意非嵌入布局的总览打开期间每 15 秒更新，收起 PC 侧栏仍追踪后台未读；页面隐藏时不请求，离开新版模式且未打开总览时取消请求。移动端和传统 PC 仅在总览打开时查询其他实例，关闭总览立即取消请求与退避，不开启 PC 侧栏或改变原导航。selector、工作区 generation 和请求版本共同隔离快照。预览复用 overview 的独立图片存储，缺少画面时显示无预览。

首次连接遇到网络失败、超时、408/425/429 或 5xx 时，以 250/750/1500/3000ms 间隔自动重试，随后由正常刷新继续恢复。请求按 selector 单飞，每个实例独立恢复，不以一个慢实例阻塞整轮刷新；退避期间释放请求槽位。物理机查询包含票据与设备网关连接，单次允许 45 秒；容器查询仍为 12 秒。认证、协议更新或无效会话身份不做快速重复请求，保留明确提示，后续刷新仍重新检查，环境恢复后无需点击实例。页面隐藏、离开目录观察范围或 dispose 同时取消请求和退避计时；恢复可见或网络上线后自动重新加载，迟到结果不能覆盖当前状态。

前端只有在容器响应显式声明 `agent_protocol_update_required` 时才显示协议更新提示，不通过通用 409 状态码推断 PC 客户端版本。

目录分别维护已确认元数据和已应用的活动 selector/generation；工作区切换期间保留缓存，只有当前代次完成权威 state apply 后才读取 live tab registry。`pending`、连接重试和确认空列表有不同语义；侧栏和预览共享目录计算的提示，临时清空 registry 不产生空列表提示闪烁；侧栏和分组预览有会话就显示列表，没有则留空，不显示停止、连接或加载的文字占位；需要处理的错误仍保留反馈。实例标题圆点在停止时为红色，首次加载、活动目标切换和连接重试期间为蓝色，成功取得会话状态后恢复绿色；已加载实例的例行后台刷新不切换为蓝点。等待新工作区期间点击会话通过现有 refresh owner 完成读取，不把暂未应用的会话误报为已关闭。

侧栏中的会话对应现有 tab，原分屏完整保留。实例标题行的名称靠左，右侧依次放置新建会话和展开收起图标。工具栏左侧为向左箭头的收起按钮，右侧依次复用文件上传和菜单入口；终端预览按钮留在原顶部栏，不移入新版侧栏。切回传统 PC 或移动布局时恢复原 DOM 位置。菜单由 instances view 在打开时挂到 body 浮层，锚定按钮下方，按可见窗口边界平移并限制高度，允许跨出侧栏范围。终端本体不属于本模块。

工具栏右侧图标统一为 16px、1.5px 线条和侧栏弱化文字色；文件上传在新版布局中使用线条纸飞机图形，切回传统或移动布局时还原原图标。按钮保留原点击区域及居中对齐，图标视觉大小与侧栏其他操作一致。

会话快捷键继续由 `app/shortcuts/` 分派，双击、F2 和改名快捷键复用 `workspace/tab_label_controller` 的原位编辑器，通过只读锚点定位到侧栏；Enter/失焦保存、Escape 取消及输入法保护沿用原实现。右键、Shift+F10/ContextMenu 键调用 `terminal/interaction.openTabMenu()`，菜单操作及当前自定义快捷键保持一致。中键关闭也走已有的会话关闭确认。

可点击的实例名称和会话选项默认显示 `pointer`。鼠标和触摸均需按住 320ms 才进入排序并显示 `grabbing`；等待期间移动达到 8px 则取消本次长按，保留点击与触摸滚动。松开、Escape、窗口失焦及其他取消路径统一清理长按计时和拖拽光标。

`reorder_controller.js` 只拥有鼠标和触摸长按的纵向拖拽、占位、自动滚动、取消和动画资源；不拥有工作区数据。会话排序使用已声明的 `tab_reorder_anchor` 能力，单次提交原子 `reorder_tab`，保留焦点和分屏，失败恢复顺序并通过现有 owner 刷新。`instance_order_controller.js` 拥有服务端账号实例顺序的读取、乐观显示和失败回退，使用 Provider 的 `api/instance-order` 公开桥接，不再读取浏览器旧的 `desktopInstanceOrder`。移动采用前后相邻 selector 锚点，不覆盖筛选掉的实例；只串行提交实例层级的顺序，不改工作区标签排序。初次显示、总览打开、每次目录刷新和恢复前台时重新读取，迟到 GET 不覆盖新提交；缺少新接口时保留可用导航，显式保存失败会提示。拖拽期间目录更新留在数据层，结束后统一呈现；不跨实例移动会话。低动态效果偏好关闭位置补间。移动端与传统 PC 分组预览的标签拖拽仍由 `terminal/overview/` 拥有，卡片携带 selector，拖拽容器限制在所属实例内；排序提交复用本模块与侧栏相同的工作区命令及失败恢复，不按裸 tab ID 操作其他实例。

`session_presentation.js` 跟踪所有真实前台进程，不以 Agent 名称白名单决定是否展示。`agent_icons.js` 与原生 AgentIcons 保持九种工具及矢量资源一致：Codex 复用已有精确识别，其余预置工具按可执行文件或实际脚本包识别；资源来源、SHA256 和许可位于 `agent_icons/LICENSE.md`，图标通过 Vite 本地打包并以模板颜色显示。未预置入口仍按可执行文件、解释器脚本或模块名展示；不解析 OSC 标题，不把命令参数、令牌或内联代码输出到 DOM。后台元数据由服务端只读检查更新，不新增终端连接或活动轮询；该状态表达进程活动，不猜测 Agent 内部的思考/等待阶段。

`session_notifications.js` 区分前台进程活动和应用工作状态；未读由应用完成次数推进，不能把持续输出或进程仍驻留当作完成。当前实例复用原有 4 秒 activity，后台实例复用目录查询；初次读取只建立基线。状态和完成次数按 selector、工作区及历史代次保留，短任务即使在两次查询间完成也能提示未读。返回实际查看的会话时只清除其未读，记录已查看输出位置以排除晚到的完成元数据；跨实例切换的中间默认会话不会被提前确认。浏览器标题汇总全部实例，收起侧栏仍更新。

侧栏在会话名称左侧预留固定状态位置，不再显示额外的终端图标：工作中显示 8 像素环逐帧亮起，完成且未读显示绿色对钩，出错显示红点。错误优先于工作，工作优先于未读；等待输入/授权保持静态，不显示成功或错误。没有可靠任务状态时位置留空，不显示「未知」图标、文字或提示；`busy` 只用于前台工具名和关闭保护，不回退成任务转圈，也不以 busy 结束生成成功未读。状态变化不移动标签；只在状态变化时替换图标，减少动态效果时使用静态工作图标。文字提示与辅助名称表达相同状态。

`program_status.js` 是已连接旧核心的实时兼容观察器，只消费成功的 live 写入，不解析历史回放；支持 OSC 7501、21337、9;4、133 和明确的标题状态/进度字符，不用工具名称白名单或输出静默超时猜测工作结束。新版核心的状态为权威来源，保留旧字段缺失才能启用此兼容。无法识别的信号不生成任务状态，普通通知、等待授权和失败不会变为成功完成。新版核心在 PTY 查询入口回答 OSC 7501 能力探测，并先于后续 DA 应答，因此任意遵循该协议的 CLI 都能直接上报，不需要名称白名单或工具专用配置。旧核心的后台实例不能提供完整应用状态，不为此额外连接或强制重建会话；完整的能力应答需要更新目标终端核心。

Codex 状态协议来源：[v0.163.0 的 terminal_program_status.rs](https://github.com/openai/codex/blob/rust-v0.163.0/codex-rs/tui/src/terminal_program_status.rs)；较早版本兼容其标题进度，不读取工具的会话文件或用户配置。

新版工作区外框统一预留 `--lzc-safe-area-inset-top`，绝对定位的侧栏也从同一安全区下沿开始，不再单独叠加顶部 padding。终端和侧栏随安全区及窗口变化一起适配；选项菜单的操作区在新版中不保留原实例列表的分隔线和底部间距。

侧栏收起后取消终端左侧 margin，终端使用完整横向空间；左侧面板为空心的展开按钮浮在左上角，不再为按钮单独预留空白。`sidebar_reveal_controller.js` 拥有展开按钮的 2 秒自动隐藏计时：支持鼠标悬停时默认显示，鼠标在左上角按钮及周围 24px 范围移动时唤出并重新计时，停止移动 2 秒后隐藏。固定感应区域不接收指针事件，通过被动监听判断附近移动，按钮隐藏后不阻挡终端操作。显隐复用工作区缓动，以 180ms 水平位移滑出屏幕左侧及滑回原位；键盘聚焦保持可见，触摸设备常驻，减少动态效果改为淡入淡出。展开侧栏、切换布局和 dispose 清理计时。恢复侧栏时复用现有几何与过渡流程。

会话行背景两侧沿用列表相同的 8px 留白，悬停与选中背景保持左右对称；内容通过 20px 左内边距保留 12px 层级缩进，以区分实例标题与子会话；任务状态槽和动画采用与 12px 标题字号一致的 1em 尺寸，空闲时也保留同宽位置，名称区域延伸到实例箭头右沿。工具图标或入口名称放在会话名称右侧的固定槽位，左侧始终只保留任务状态位置。支持鼠标悬停的布局中，鼠标悬停或键盘聚焦会话时，关闭按钮在同一槽位替换工具提示，移出且失焦后恢复；工具提示及关闭按钮切换不改变名称可用宽度或行高，没有工具时也保留该槽位。折叠屏内屏和平板的触摸布局中，关闭按钮常驻并参与行内排版，工具图标或工具名保持可见并显示在关闭按钮左侧；会话聚焦不隐藏工具提示，避免两者重叠。侧栏收放按钮使用固定左侧面板轮廓：侧栏展开时以实心左侧面板表示可收起，侧栏收起时以空心左侧面板表示可展开；图标不含大于号、小于号或箭头，不镜像面板位置。`session_label.js` 通过实际字体度量和 ResizeObserver 将名称显示为最多两行，足够容纳时显示完整名称，超过两行时在中间省略并保留开头与末尾；显式分行按 Unicode 字素边界切分，不拆开 emoji 或组合字符。字体加载和标签宽度变化后重新计算，悬停、辅助名称及原位改名保留完整名称，删除会话和销毁时释放观察。

`sidebar_resize_controller.js` 独立拥有右侧分隔线的 pointer capture、键盘操作和 RAF 合并，最大宽度为窗口的三分之一，最小宽度为 160px（受最大值约束）。宽度保存在 `${storagePrefix}.desktopSidebarWidth`，窗口变窄时仅约束显示宽度。拖动经注入的 begin/update/end 命令复用终端交互式 resize，不新建会话或改变分屏。取消、切换实例、切换布局、收起及 dispose 统一结束交互；Escape 取消当前拖动，方向键、Home/End 可调整宽度。

手工验证：容器/物理机/停止实例、跨实例同名会话、包含分屏的会话、创建/关闭/双击改名、移动端和传统 PC 全部实例预览与跨实例选择、服务端实例排序与管理页/另一设备的同步、保存失败回退、实例内长按排序及取消、持续输出期间的滑动与惯性、关闭总览后停止后台查询、预览选择、侧栏及实例连续收放、减少动态效果、传统布局开关、移动布局和窗口尺寸变化；冷启动或短暂断网后自动恢复、后台失败保留已有会话、取消与恢复加载、平板/折叠屏顶部安全区及菜单分隔线。产品合同见 `spec/workspace/desktop-navigation/` 与 `spec/terminal/overview-preview/`。
