# 工作区标签栏拖拽排序

## 背景

用户在包含多个终端标签的工作区中，需要像浏览器标签栏一样直接拖动标签调整顺序，并在后续打开工作区时保留该顺序。

## 需求目标

- 桌面布局中，用户可以在顶部标签栏内拖动标签到任意位置；拖动非活动标签时，该标签立即成为活动标签。
- 一次拖放只提交一个排序结果。排序成功后，当前页面立即显示新顺序，刷新页面及同一工作区的其他页面最终显示相同顺序。
- 强制 PC 模式，以及顶部标签栏可见的折叠屏大屏和平板触摸布局，通过长按标签开始拖动；该手势不打开鼠标右键菜单。
- 折叠屏大屏和平板的标签栏溢出时，用户可以在长按生效前直接横向滑动浏览标签；滑动不激活标签、不改变顺序，也不提交排序。
- 窄屏普通移动布局不显示顶部标签拖拽入口，继续通过终端总览浏览和整理标签。

## 范围

仅支持同一工作区、同一顶部标签栏内的标签重排，包括鼠标、触控笔，以及强制 PC 模式、折叠屏大屏和平板布局下的触摸操作。

## 非目标

标签拆分为新窗口、跨窗口或跨工作区拖放、终端进程迁移，以及改变已有菜单和快捷键排序行为均不在本需求范围内。

## 兼容性

顶部拖拽只在当前 workspace agent 明确支持原子锚点排序时启用。连接旧 agent 时保留已有标签使用方式，不通过多次相邻移动模拟拖拽提交。
