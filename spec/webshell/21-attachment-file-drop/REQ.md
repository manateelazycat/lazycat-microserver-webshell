# 拖到目标终端后完成上传并写入路径

## 背景

授权用户通过浏览器使用 WebShell。用户需要把本地图片或文件交给远端终端使用时，如果只能打开文件管理再手动选择，拖放没有反应，大文件也看不到进度，用户会以为操作失败或页面卡住。

## 需求目标

用户把文件拖到某个终端画面并松开后，该画面先给出可放下的确认，松开后显示上传进度，成功后远端路径只进入松开时所在的终端一次，且不会自动执行。

## 范围

覆盖桌面浏览器中把本地文件拖到终端画面、分屏时按指针所在画面落点、上传进度，以及把路径写入该终端。拖到非终端区域不得离开当前页面，也不得上传。

## 非目标

不覆盖文件夹上传、移动端拖放、从网页只拖入地址、以及左上角文件管理中的手动选择上传。
