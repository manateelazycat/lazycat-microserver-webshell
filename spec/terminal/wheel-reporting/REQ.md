# 触控板滚动按位移上报给终端程序

## 背景

用户通过 macOS Chrome 使用 WebShell 中开启鼠标上报的 pi 等终端程序时，触控板轻微滑动会滚过大量内容。连续的小幅滚动和惯性尾部都被当成完整滚轮输入，导致精细定位困难；同一实例的普通终端历史回滚没有这一现象。

## 需求目标

终端程序收到的滚轮输入随累计滚动位移变化，不因浏览器把同一位移拆成更多事件而放大。像素位移按当前终端行高换算，累计一行对应一次滚轮输入，不足一行的位移保留用于后续同方向滚动。

浏览器明确标记的惯性滚动不继续转发给终端程序。浏览器未提供惯性标记时仍按位移换算，保留用户慢速滚动的能力。

## 范围

覆盖 WebShell 中开启鼠标上报的终端程序，支持浏览器以像素、行或页表达的滚动位移。滚动余量只属于当前会话和鼠标模式，反向滚动重新累计。

## 非目标

不改变普通终端历史回滚、移动端触摸手势或终端程序每次滚轮输入对应的内容行数；不根据事件频率或位移衰减猜测惯性。
