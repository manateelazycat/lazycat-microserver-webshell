# 原生客户端与 Web 终端的行内图片一致性

## 背景

用户在 LightOS 终端使用 Codex 等输出 Kitty Graphics 的远端程序，需要在原生客户端和 Web 客户端查看图片，而非看到协议文本或缺失的缩略图。

## 需求目标

相同网格、单元格像素尺寸与图片协议输出下，两端图片的尺寸、位置、裁剪、层级及随文字移动的行为一致，并与 Ghostty 的终端图片语义一致。调整终端尺寸、滚动及切换标签后，图片保持与所属终端内容的对应关系。

## 范围

Kitty Graphics 的 direct 传输、PNG/RGB/RGBA 图片、普通及 Unicode 占位放置、删除、图层和受支持的动画；以随包 Ghostty 官方实现支持的协议范围为准。

## 非目标

不移植 Ghostty 桌面 UI，不自动下载打印出的任意图片 URL，不开放客户端本地文件或共享内存读取。图片会话继续使用现有原始历史回放；不新增已裁剪历史之外的图片恢复承诺。旧 Agent 不自动替换，既有进程不自动重启。
