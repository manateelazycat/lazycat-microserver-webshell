# 物理机实例的交互式 SSH

## 背景

PC 客户端和 hclient-cli 的用户希望从系统终端或标准 SSH 软件访问自己的电脑，而不必始终打开浏览器终端。电脑可能保存多个微服账号，因此访问必须受当前活动账号和客户端接入开关控制。

## 需求目标

当前活动账号启用独立 SSH 访问并设置密码后，可以通过该实例的连接命令进入目标电脑的交互终端，使用客户端进程所属的本机用户权限。每次 SSH 登录获得独立终端，不接管浏览器已有会话。

密码由用户自行设置，只要求非空，不设最短长度、复杂度或 72 字节上限，不截断或裁剪；只有完整正确的密码可以登录，升级后既有密码仍可用。用户有从连接开始共 120 秒确认主机指纹并完成密码认证，不能因为输入超过 10 秒就断开；超时和未授权连接仍被关闭。

SSH 默认关闭。关闭 SSH、修改密码或成功切换接入端口时，已有 SSH 连接和所属任务被回收，浏览器终端继续可用。关闭整个客户端接入、账号切换或授权失效时，旧账号不能继续访问；旧配置和迟到连接不能恢复被撤销的访问。

## 范围

覆盖 Linux、macOS 和 Windows 的物理机实例，标准 SSH 密码认证、交互 shell、PTY、窗口调整、输入输出、退出。扩展支持无 PTY/有 PTY exec、SFTP、现代及传统 SCP、本地/远端/动态 TCP 转发、跳板、Agent 和 X11 转发，以及环境变量、信号和平台支持的 PTY modes。每条连接可并发使用至多 32 个通道，使用客户端进程所属本机用户的文件和网络权限；不由微服代执行命令或拨号。

交互 shell 意外断线后，在客户端终端进程存续期间持续保留，不设自动到期时间。同一账号重新认证后可列出、续接或终止自己的会话，最多 32 个终端；续接拒绝并发写入，回放最近 1 MiB 输出并提示缺失。正常退出的会话移除；断线期间自行退出的会话在容量需要复用前可读取最终输出与退出结果，名额用尽时优先清理已退出记录，不回收运行中的任务。短暂无法验证云端身份只暂停新接入，不结束已启动的任务；明确关闭 SSH、改密或成功换端口、账号切换、关闭整个客户端接入或客户端进程退出仍回收。exec、文件传输和转发不自动续接；Agent/X11 通道及凭据随原连接释放。

远端 TCP 转发默认回环监听，用户显式指定绑定地址时可在本机权限内使用；Agent/X11 只按客户端显式请求建立。SFTP 从用户主目录开始，按本机权限访问文件系统，不额外限定到浏览器目录。环境变量接受 LANG、LANGUAGE、LC_*、COLORTERM 和 TERM；拒绝覆盖 HOME、PATH、加载器或认证变量。Unix 应用 RFC 4254 的可支持终端模式与信号；Windows 采用 ConPTY 模式，不能模拟的模式/信号明确拒绝。X11 要求发起连接的一侧有可用显示服务器。

微服接入端口范围为 1024–65535，须可达且无冲突。SSH 用户名是授权微服账号；独立密码不改变微服或本机登录密码。主机身份正常重启后保持稳定。

## 非目标

不安装或修改系统 SSH 服务，不提升本机权限，不改变容器 SSH 或浏览器工作区。不新增公钥登录、多人共享授权或默认 Shell 选择设置。不保证客户端进程重启后恢复任务，也不自动恢复已断开的 TCP、SFTP 或 SSH 传输。VS Code Remote SSH 不作为本批次独立验收目标。移动端不作为 SSH 服务提供方。网络可达性由部署环境保证，不承诺未验证的公网直连。
