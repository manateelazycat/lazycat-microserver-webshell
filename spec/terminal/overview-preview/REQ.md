# 刷新页面后总览仍显示已保存的终端预览

## 背景

授权用户通过浏览器使用 WebShell。工作区多个标签已有可见内容和已保存预览时，相关交互的回归会影响用户继续使用终端。

## 需求目标

总览仍能显示对应标签上次保存的预览。

移动端预览列表超出一屏时，用户可以从卡片区域连续上下滑动并惯性滚动到列表两端，后台预览更新不打断滑动或改变当前阅读位置。开始滑动后取消该次长按排序候选，只有按住不移动后才进入拖拽；普通滑动不切换、关闭或重排标签。滚动结束后继续更新预览，关闭总览后不保留拖动状态或拦截后续触摸。

## 范围

用户刷新页面并在后台标签尚未完成实时呈现时打开总览，并保护本功能对应的外部结果。

覆盖移动端总览预览列表的纵向滚动与长按排序边界。

## 非目标

预览容量和过期清理策略另行验收。
