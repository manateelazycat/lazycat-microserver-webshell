# 移动端终端预输入

## 背景

移动端用户需要先编辑文字、选择图片或文件，再将完整内容发送到当前 WebShell 终端。

## 需求目标

- 终端设置提供默认关闭的预输入框开关；开启后在移动端快捷键栏下方显示可编辑的多行草稿。
- 左侧工具按钮提供相册和文件入口；选中的附件先在输入框上方展示，支持移除，此时不上传。
- 草稿有文字或附件时显示右侧发送按钮。点击后按选择顺序逐个上传附件，将全部路径置于文字前，一次发送到当前终端，不自动追加回车。
- 发送期间显示进度并阻止重复发送；失败保留草稿，重试复用已成功上传的附件路径。切换终端不能将旧草稿误发到新终端。

## 范围

移动端开关持久化、文字编辑、附件待发送预览、顺序上传、路径与文字组合、发送及失败重试。仅附件也允许发送；路径含空格等字符时保持完整。

## 非目标

桌面端预输入、自动执行命令、改变既有快捷键和文件管理交互。
