# 历史达到上限后仍能恢复完整终端

## 背景

长期运行的 TUI 可能只更新底部区域。按字节截断的历史会移除主体绘制和终端初始状态，新页面仅回放历史尾部时出现上部空白；反复重绘无法修复，必须由应用重新输出才能恢复。

## 需求目标

支持状态恢复的容器终端在历史达到保留上限后，用户重新进入仍能获得完整主体、光标及终端模式，并继续交互，无需手动调整尺寸。恢复期间产生的新输出按序应用，不重复或遗漏。

## 范围

当前协议 Agent 的普通容器 PTY 与支持状态恢复的浏览器。每个会话保持独立状态，恢复使用明确游标边界，显示前遵守既有回放及尺寸事务。浏览器的默认主题与程序主动设置的颜色分别保留。

## 非目标

不自动替换旧 Agent 或重启用户任务。旧协议、客户端主机终端和 Kitty 图形会话沿用既有回放路径；本次不实现图形资源的服务端状态恢复。不承诺跨不同引擎构建直接导入内部状态。
