# 手机和平板长按选中连续文字

## 背景

用户在手机或平板的 WebShell 终端中长按文字时，初始选区仅覆盖触摸处及相邻的一小部分文字，复制完整单词、文件路径或中文短句前，需要反复拖动选区手柄。

## 需求目标

长按文字时，终端自动选中触摸位置所属的连续字符串：英文按单词、文件名或路径选择，中文按空白和标点分隔的连续短句选择。文本的宽字符、emoji 及组合字符保持完整，长按宽字符的任一半格得到相同范围。

空白、标点和终端边框隔开不同片段，长按这些边界时不误选相邻内容。可以确认的自动折行延续同一字符串；不把独立的行或界面列拼成一句话。

长按后的轻微抖动不缩小初始字符串选区，继续拖动可以扩选，松手后仍能用手柄精细缩小或扩大选区。原有滚动、点击、键盘调用和选区操作栏保持可用。

## 范围

覆盖手机和平板的触摸选择布局、普通终端以及已适配 WebShell 本地长按选区的全屏终端程序。跨行自动扩选覆盖当前屏幕中可以确认自动折行的相邻文本。

## 非目标

不按英文空格自动选择整句，不进行语义分析或推断缺少折行信息的历史行，不改变桌面双击、鼠标拖选和现有复制格式，不扩大未适配程序的手势接管范围。
