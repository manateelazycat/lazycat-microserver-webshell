# 可关闭的终端自动补绘

## 背景

用户进入终端页面时偶发内容显示不完整，调整窗口后恢复。自动补绘用于缓解已有正确内容未完整显示的问题，不能替代对终端状态错误的修复。

## 需求目标

可见终端在进入、恢复显示后自动补绘，并在可识别的画面更新未完成时进行有限恢复。调试模式内提供“自动刷新屏幕”开关，默认开启，关闭后停止这项机制，选择在本浏览器重新进入页面后保留。

## 范围

本浏览器的终端显示兜底及其独立开关。调试模式只控制开关入口是否展示，关闭调试模式不改变自动补绘的启用状态。补绘保留内容、滚动位置和其他设备的终端尺寸控制权。

## 非目标

不保证修复所有视觉异常，不重启会话、不重新回放历史、不强制 TUI 输出，也不通过反复改变远端尺寸实现刷新。
