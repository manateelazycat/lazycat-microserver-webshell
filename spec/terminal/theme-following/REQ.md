# Codex 输入区域跟随 WebShell 主题

## 背景

用户在 WebShell 中运行 Codex 时，切换主题后文字会变化，但输入区域仍保留启动时的背景色。用户必须重新启动 Codex 才能让输入区域适配当前主题，打断了正在进行的输入和工作。

## 需求目标

用户在同一 Codex 进程运行期间连续切换 WebShell 主题，输入框及使用相同派生背景的区域立即跟随当前主题，未提交文字和会话状态保持不变。其他程序的显式配色不因 Codex 适配发生变化。

## 范围

覆盖 WebShell 默认终端配色模式下、可识别为 Codex 的会话，以及 WebShell 主题选择器提供的主题。包括先切换主题再启动 Codex、连续切换深浅主题、刷新页面或重新连接同一 Codex 进程后的主题切换。

## 非目标

本次不覆盖 Codex 所有元素、代码高亮和自定义配色，不修改 Codex，不通过重新启动进程实现换色。用户自行改变终端颜色能力或在程序中设置的任意背景色不在本次适配范围。
