# 客户端按需整机指标

## 背景

用户希望在 LightOS 首页查看客户端设备的资源状态，但不希望无人查看时客户端仍持续采集或上报监控数据。

## 需求目标

当前所属账号查看首页时可以读取客户端整机的累计 CPU、内存及磁盘 I/O 数据供卡片展示。没有请求时不持续采样，不创建监控进程或定时采集任务；取消请求或接入授权失效时不再续发采样。未支持或失败的单项数据明确不可用，不能返回伪造的零值。

指标访问复用当前设备、账号及接入代次的终端门禁，不依赖独立 SSH 开关。采样不创建、关闭或修改浏览器/SSH 终端。

## 范围

Linux、macOS、Windows 的 PC 与 hclient-cli 共用采样和受控只读入口；平台原生单次读取允许在取消后有限收尾，多个查看者可复用短时原始快照。前端负责差分、显示和页面离开后的请求取消。

## 非目标

不修改容器或移动端，不提供进程列表、命令行、磁盘序列号、路径、指标历史存储或常驻监控。
