# 定位终端网络流量的消费来源

## 背景

用户通过网络监视器发现终端会话产生了异常的大流量时，只能看到会话和标签的总量，无法判断流量来自历史回放、实时输出、输入还是连接控制逻辑。

## 需求目标

调试终端网络问题的用户可以把网络监视器已统计的流量按固定的模块和任务拆分，稳定比较每类终端行为的消费量，核对分类合计与原总流量一致，并复制结构化数据用于进一步分析。

## 范围

网络监视器所观察的终端会话 WebSocket 载荷、固定顺序的流量消费分类、当前速率与累计接收/发送量、JSON 数据复制，以及调试窗口的显示和生命周期。

## 非目标

不增加 HTTP、附件或浏览器资源等新的流量统计来源，不估算 TLS、TCP 或 WebSocket 帧开销，也不作为网络计费依据。
