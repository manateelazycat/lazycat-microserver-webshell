# 网络流量在工作区顶部栏分层展示

## 背景

用户在调试终端连接时需要持续观察实时速率、累计流量和网络状态。浮在终端内容上方的监视窗口会遮挡输出，也无法直接区分不同标签页产生的流量。

## 需求目标

开启网络监听后，用户可以在不遮挡终端内容的顶部栏查看所有会话的汇总流量和网络状态，并在每个标签页上查看该标签内全部会话的汇总流量。

## 范围

调试模式下网络监听器的运行门控、桌面端和移动端顶部栏总览、桌面端标签页流量摘要，以及同一标签内多个会话的数据汇总。

## 非目标

不提供生产环境流量计费依据，不展示已关闭标签的历史流量，也不改变终端连接、重连或标签页管理行为。
