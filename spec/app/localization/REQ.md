# WebShell 界面使用一致的中英文文案

## 背景

英文环境下，设置窗口中的光标样式、平滑光标和字体大小仍显示中文；左侧分类重复使用 Settings，名称过长。附件、剪贴板、截图、服务转发、诊断和错误提示也存在翻译遗漏。

## 需求目标

英文环境下，设置窗口的光标样式、选项、平滑光标说明、字号说明、增减和恢复默认按钮及校验错误均显示英文。设置分类使用 Terminal、Theme、Mobile Shortcuts、PC Shortcuts 和 Service Forwarding，桌面侧栏和移动分类列表保持一致。

字号区域只显示一次“字体大小 / Font Size”标题，下方只保留范围、默认值和立即生效的说明，不重复展示“字号 / Font size”字段标签；输入框仍有对应语言的无障碍名称和说明。

附件上传、剪贴板粘贴、搜索与复制、长截图、服务转发、会话关闭确认和诊断界面的固定文案及反馈使用相应语言。动态提示里的数量、路径和用户命名保持原值；动态更新的标题、占位文字与无障碍标签也按当前语言呈现。

中文环境沿用中文文案。语言处理不改变设置值、命令、路径或终端交互。

## 范围

WebShell 自有界面中的中英文词条、动态提示和设置分类名称。

## 非目标

不翻译用户命名、文件内容、终端程序输出或第三方服务返回的任意错误内容，不改变已有语言选择方式。不新增自动真机测试代码，由开发者手工验收。
