# 在终端设置中查看和调整当前字号

## 背景

WebShell 已支持通过快捷键调整字号，但终端设置中缺少显示当前字号和直接输入字号的入口，用户无法从设置面板确认或精确调整字体大小。

## 需求目标

终端设置按字体、光标样式、字体大小的顺序显示。字体大小输入框默认显示当前实际使用的字号，并与已有快捷键调字号保持同步。

字体大小标题与范围、默认值和生效说明之间保持紧凑间距，说明及输入控件仍清晰可读。

字体大小采用与历史行数一致的数字输入和上下增减交互，范围沿用 10–32px，默认值为 16px。字号、行间距和历史行数旁不显示圆形的恢复默认按钮，用户仍可直接输入所需数值。有效修改立即应用于已有终端，后续新建终端使用相同字号；重新打开设置或在同一浏览器刷新页面后保留字号。

提交空值、非整数或越界字号时，保留当前字号，输入框恢复当前值并显示错误反馈。调整字号不丢失未提交输入或会话内容。

## 范围

覆盖终端设置中的字体大小入口、现有字号快捷键与输入框的同步，以及同一浏览器中现有的字号保存范围。

## 非目标

不改变字号范围、快捷键定义、服务端设置或不同设备间的字号同步，不重做字体加载和终端尺寸调整流程。
